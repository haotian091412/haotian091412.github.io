# Haotian Ma — Online CV

A responsive, accessible academic CV built as a static site for GitHub Pages.

## Local preview

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Publish

Create a public repository named `haotian091412.github.io`, push this directory to its `main` branch, and GitHub Pages will serve it at <https://haotian091412.github.io/>.
